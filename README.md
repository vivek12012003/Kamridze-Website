# Kamridze International Public School Website

## 📌 Project Overview
This is a responsive school website developed for Kamridze International Public School, Chourai.  
It provides information about academics, facilities, and school activities.

## 🚀 Features
- Responsive design (mobile + desktop)
- Clean and modern UI
- Sections for:
  - About School
  - Academics (Nursery to 12th)
  - Facilities
  - Contact Information
- Easy navigation

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
